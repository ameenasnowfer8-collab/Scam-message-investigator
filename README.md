# Scam Message Investigator

## About

Scam Message Investigator is an AI-powered application that analyzes suspicious messages and identifies possible scams. It helps users understand online threats and stay safe.

## Technologies Used

* Python
* Streamlit
* Ollama
* Gemma 3 1B
* Requests

## Features

* Analyzes suspicious messages.
* Identifies possible scam messages.
* Displays risk levels.
* Highlights warning signs.
* Provides safety recommendations.

## Installation

1. Install Python.
2. Install Ollama.
3. Download the AI model:

```bash
ollama pull gemma3:1b
```

4. Install the required libraries:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python -m streamlit run app.py
```

## Conclusion

This project uses Artificial Intelligence to identify potentially suspicious messages and helps users protect themselves from online scams.
